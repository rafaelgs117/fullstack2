# SOS Emergência — Página institucional

Projeto Next.js com Tailwind CSS, responsivo com `sm`, `md` e `lg`.

## Executar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Deploy na Vercel

Este projeto pode ser importado separadamente na Vercel.

Ao criar o projeto na Vercel, selecione:
- Framework Preset: **Next.js**
- Root Directory: `next-app`
- Build Command: `npm run build`
- Install Command: `npm install`

A Vercel detecta automaticamente o Next.js e gera o link público após o deploy.
