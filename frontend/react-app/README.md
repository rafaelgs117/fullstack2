# Front-end React — SOS Emergência

```bash
npm install
npm run dev
```

O Vite normalmente disponibiliza `http://localhost:5173`. A API deve estar em `http://localhost:3000`.

## Acesso didático

Login `luna`, senha `1234`. A API deve ter sido preparada com `npm run seed:luna` no diretório `backend`. Após o login, o front-end guarda o JWT localmente e envia o token nas chamadas protegidas. Use apenas para a atividade acadêmica.
